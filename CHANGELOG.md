# Changelog

All notable SimProof changes are recorded here. The project follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) structure and applies semantic
versioning as defined in the [release and support
policy](docs/operations/releases-and-support.md).

## [Unreleased]

### Added

- Initial single-tenant teacher application with authenticated web, orchestrator,
  SQLite/content-addressed persistence, provider ports, lifecycle, publication, export,
  backup/restore, and local diagnostics.
- Trusted projectile and pendulum domain packs with versioned policy evidence,
  scientific conformance, accessible representations, and stale-report handling.
- Network-disabled generated-code runner, bounded Docker launcher, and supported Linux
  Docker Compose deployment.
- Production repository gates covering formatting, lint, typed boundaries, scientific
  verification, migrations, integration, security, diagnostics, accessibility,
  deployment, proof parity, and builds.
- Apache-2.0 code license, CC BY 4.0 bundled-content license and notice, contribution and
  conduct guides, private security-reporting policy, public issue/PR templates, and
  release/support guidance.

### Security

- Generated code is restricted to disposable, unprivileged containers with no network,
  secrets, host/data mounts, repository, devices, or Docker socket.

Releases and comparison links will be added only after an authorized public release.
